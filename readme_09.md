# [ชื่อชื่อโปรเจกต์ - Project เตือนฉันที]
> สรุปคำอธิบายสั้น ๆ 1 ประโยคว่าโปรแกรมนี้ทำหน้าที่อะไร (เช่น: เตือนว่าต้องทำอะไรแม้ปิดแท็บแอป)

📌 1. ที่มาและความสำคัญ (Introduction)
อธิบายสั้น ๆ ว่าทำไมนักเรียนถึงเลือกสร้างโปรเจกต์นี้ขึ้นมา 
เพราะผมเป็นคนที่ชอบลืมบางอย่างเพราะงั้นจึงสร้างแอปนี้ขึ้นมา

* **ปัญหาที่พบ:** ไม่สามารถทำให้เสียงที่ตั้งไว้ในแต่ละหมวดหมู่ใช้ได้ทั้งโค้ดและแอปเลย(แต่ตอนนี้ได้ทำการแก้ไขแล้วครับ)
* **เป้าหมาย:** อยากให้สามารถเเจ้งเตือนได้แม้จะไม่ได้เปิดแท็บแอปค้างไว้

## 🚀 2. ความสามารถของโปรแกรม (Features)
* [มี DARK และ LIGHT โหมด] ฟีเจอร์ที่ 1
* [สามารถบันทึกข้อมูลที่สั่งให้แจ้งเตือนได้และเมื่อปิดแอปจะสิ่งที่ทำการบันทึกในการแจ้งเตือนจะไม่หาย] ฟีเจอร์ที่ 2
* [สามารถเล่นเสียงตามหมวดหมู่ที่เลือกได้ถ้าไม่ได้นำเสียงเข้าแอป] ฟีเจอร์ที่ 3

## 🛠 3. เครื่องมือที่ใช้ (Tech Stack)
* **Language:** Python
* **Library/Framework:** Tkinter,winsound,threading,datetime,json,PyInstaller
* **Design Tool:** Canva
